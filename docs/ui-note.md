# UI 说明：秤心

- **谁在什么时刻打开**：给只想回看日常饮食的人。
- **首屏任务句**：这一餐，实际吃了什么。
- **主操作**：按「拍一张餐盘 → 逐项确认食物 → 改份量后重算」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：营养摄影记录；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：营养摄影记录。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给只想回看日常饮食的人：拍一餐后逐项确认食物和估计份量，看不清就给可编辑区间或留空；修正后按营养表重算，并显示数据出处。
